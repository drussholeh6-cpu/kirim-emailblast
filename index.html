Panduan Arsitektur Email Massal Dunia Nyata

Karena batasan keamanan peramban (CORS & sertifikat TLS), browser tidak diperbolehkan secara langsung membuka koneksi socket TCP ke Port SMTP 587/25 atau mengirimkan pesan langsung ke jutaan email.

1. Alur Arsitektur Produksi (Production Pipeline)

[Frontend / Web UI] ➔ (API Request / JSON) ➔ [Backend Service: Node.js / Python / PHP] ➔ (Job Queue / Redis) ➔ [Email API Provider: Resend / AWS SES / SendGrid] ➔ [Inbox Penerima]

2. Contoh Backend Node.js (Express + Resend API)

// server.js (Node.js Backend)
const express = require('express');
const { Resend } = require('resend');
const resend = new Resend('re_YOUR_API_KEY');
const app = express();
app.use(express.json());

app.post('/api/send-bulk', async (req, res) => {
  const { contacts, subject, bodyHtml } = req.body;
  
  for (const recipient of contacts) {
    await resend.emails.send({
      from: 'MailBlast ',
      to: recipient.email,
      subject: subject.replace('{{nama_depan}}', recipient.name),
      html: bodyHtml
    });
  }
  res.json({ success: true, message: 'Batch terkirim' });
});

app.listen(3000);

3. Syarat Penting Agar Email Tidak Masuk Spam:

  • SPF (Sender Policy Framework): Mengautentikasi server mana yang berhak mengirim atas nama domain Anda.
  • DKIM (DomainKeys Identified Mail): Tanda tangan digital kriptografi untuk mencegah manipulasi email.
  • DMARC: Kebijakan keamanan tambahan untuk verifikasi validitas email.
  • Unsubscribe Link: Wajib menyertakan link pembatalan langganan di footer email.
